# CloudLog Pro - Enterprise Log Analyzer

A modern, feature-rich log analysis tool for cloud environments.

## Features

- Multi-format log parsing (Apache, Nginx, common formats)
- Advanced analytics and insights
- Interactive visualizations
- Export capabilities (JSON/CSV)
- Real-time analysis
- Security scoring
- Performance metrics

## Deployment on Render.com

### One-Click Deploy

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

### Manual Deployment

1. Fork this repository
2. Create a new Web Service on Render.com
3. Connect your repository
4. Use the following settings:
   - **Runtime:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn main:app --timeout 120 --workers 2 --threads 2`
   - **Plan:** Free (or choose appropriate plan)

### Environment Variables

- `SECRET_KEY`: Auto-generated by Render (or set manually)
- `FLASK_ENV`: Set to `production`
- `PYTHONUNBUFFERED`: Set to `true`
